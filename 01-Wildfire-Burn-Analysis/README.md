
# Wildfire Burn Patterns and Elevation in the Bridger Range, Montana

## Project Overview

This project examines wildfire burn patterns, vegetation classification, and elevation characteristics in the Bridger Range, Montana, using satellite imagery and geospatial analysis in ArcGIS Pro.

The analysis integrates satellite imagery, classified vegetation raster data, and digital elevation models (DEMs) to visualize wildfire impacts and terrain characteristics.

## Objectives

- Visualize wildfire burn patterns using satellite imagery.
- Examine burned and unburned vegetation classes.
- Analyze elevation distribution within the study area.
- Produce a cartographic layout integrating maps, charts, and geographic context.

## Data Sources

- Satellite imagery: Planet four-band imagery (BridgBurn090920).
- Burn classification: ClassBrigBurn raster dataset.
- Elevation: DEM Broad and DEM focus.
- Basemap: Esri World Topographic Map and World Hillshade.
- Data provided through GPHY 504, Montana State University.

## Methods

The project was completed using ArcGIS Pro.

1. Visualized four-band satellite imagery of the Bridger Range.
2. Used classified raster data to examine burned and unburned vegetation.
3. Analyzed elevation distribution using a digital elevation model.
4. Generated an elevation histogram and vegetation burn-classification chart.
5. Created a map layout incorporating satellite imagery, charts, a legend, and a study-area location map.

## Key Findings

- Elevation ranged from approximately 1,693 to 2,371 meters.
- Mean elevation was approximately 1,964 meters.
- Burned trees accounted for 39,460 classified pixels.
- Burned grass accounted for 10,663 classified pixels.
- Unburned trees and grass accounted for 4,771 and 111 pixels, respectively.

The classification results suggest that wildfire impacts were particularly extensive in areas classified as forest vegetation.

## Coordinate Reference System

- CRS: WGS 1984 UTM Zone 12N (EPSG:32612)
- Projection: Transverse Mercator
