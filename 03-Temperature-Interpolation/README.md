
# Temperature Differences and Prediction Standard Errors Across Africa and the Arabian Peninsula

## Project Overview

This project examines spatial patterns in temperature differences and prediction uncertainty across Africa and the Arabian Peninsula using GIS-based spatial interpolation and visualization in ArcGIS Pro.

The analysis presents January and August temperature prediction standard errors alongside spatial differences in temperature.

## Objectives

- Visualize the spatial distribution of temperature prediction uncertainty in January and August.
- Compare seasonal patterns in prediction standard errors.
- Map geographic variations in temperature differences.
- Produce a cartographic layout showing the three spatial patterns.

## Methods

The project was completed using ArcGIS Pro.

1. Generated spatial representations of temperature prediction standard errors for January and August.
2. Visualized spatial patterns in temperature differences.
3. Applied graduated color schemes to distinguish geographic variation.
4. Created a three-panel map layout with legends, geographic boundaries, and a north arrow.

## Map Outputs

- January Prediction Standard Error (°C)
- August Prediction Standard Error (°C)
- Temperature Difference (°C)

## Software

- ArcGIS Pro
- Geographic Information Systems (GIS)
- Spatial Data Visualization
