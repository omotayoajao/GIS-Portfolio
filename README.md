## About This Portfolio

This repository showcases my GIS, remote sensing, spatial analysis, and environmental mapping projects completed using ArcGIS Pro. My work explores applications of geospatial techniques in ecology, environmental science, conservation, and land-use planning.

- Remote Sensing and Satellite Imagery
- Raster and Vector Spatial Analysis
- Spatial Interpolation and Geostatistics
- Georeferencing and Cartography
- Species Distribution Modeling
- Environmental Data Visualization
