
# Digital Surface Model (DSM) and Hillshade of the UAV Study Area

## Project Overview

This project uses Unmanned Aerial Vehicle (UAV) imagery to generate and visualize a Digital Surface Model (DSM) and hillshade of a study area using ArcGIS Drone2Map and ArcGIS Pro.

The analysis demonstrates how UAV photogrammetry can be used to represent surface elevations, including buildings, vegetation, and terrain features.

## Objectives

- Generate a Digital Surface Model from UAV imagery.
- Visualize surface elevation differences across the study area.
- Produce a hillshade representation of surface features.
- Create a cartographic layout showing elevation patterns and surface characteristics.

## Data Sources

- UAV RGB imagery supplied for GPHY 504 Lab 9, Montana State University.
- Reported ground resolution: 0.015 m (1.5 cm).
- Coordinate Reference System: WGS 1984 UTM Zone 12N.
- Vertical Reference System: EGM96 Geoid.

## Methods

The project was completed using ArcGIS Drone2Map and ArcGIS Pro.

1. Used UAV RGB imagery for photogrammetric processing.
2. Generated a Digital Surface Model representing surface elevations.
3. Visualized elevation differences using a continuous color gradient.
4. Displayed shaded relief to emphasize surface features.
5. Produced a final map layout with an elevation legend, north arrow, scale bar, and coordinate information.

## Map Interpretation

The DSM represents elevation variations across the study area, including buildings, vegetation, and surrounding terrain.

The elevation values displayed on the map range from approximately 1473.57 m to 1494.55 m.

The hillshade enhances the visual interpretation of surface features and elevation differences.

## Software Used

- ArcGIS Drone2Map
- ArcGIS Pro
